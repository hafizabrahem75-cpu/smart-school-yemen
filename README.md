# مدرستي الذكية | Smart School Yemen

منصة عربية تعليمية تفاعلية، تبدأ بالصف التاسع — الرياضيات، وتستهدف الويب وAndroid عبر تطبيق ويب تقدمي (PWA).

## ما يعمل في النموذج الأولي

- واجهة عربية RTL متجاوبة مع الهاتف والحاسوب.
- أربع بطاقات دروس أولية: الأعداد الحقيقية، المعادلات الخطية، الهندسة والقياس، العلاقات والتمثيل البياني.
- نافذة شرح لكل درس وزر لحفظ إكماله.
- مختبر تفاعلي للعلاقة ص = ٢س + ١.
- سؤال اختباري مع تصحيح وشرح.
- حفظ التقدم محلياً في المتصفح.
- ملف PWA وService Worker لتخزين ملفات الواجهة والعمل دون اتصال بعد أول زيارة ناجحة.
- لا توجد مفاتيح API أو خدمات مدفوعة مطلوبة للنموذج الحالي.

## تشغيل محلي

افتح `index.html` عبر خادم ملفات محلي. يلزم استخدام localhost أو HTTPS لتفعيل Service Worker وميزات التثبيت.

## النشر على GitHub Pages

ملف سير العمل `.github/workflows/pages.yml` ينشر محتويات المستودع عند الدفع إلى `main`. أول مرة:
1. افتح Settings ثم Pages في المستودع.
2. اختر GitHub Actions كمصدر للنشر.
3. احفظ الإعداد، ثم راقب تبويب Actions.

بعد نجاح النشر سيكون عنوان الموقع عادة:
`https://hafizabrahem75-cpu.github.io/smart-school-yemen/`

## ملاحظات مهمة

- هذه نسخة تجريبية أولية وليست بعدُ نسخة مطابقة معتمدة للكتاب المدرسي اليمني. ترتيب الوحدات والمحتوى الحاليان توضيحيان، ويجب تدقيقهما مقابل نسخة الكتاب/المنهج المعتمدة قبل تقديمهما للطلاب على أنهما المنهج الرسمي.
- التقدم محفوظ على الجهاز نفسه ولا توجد حسابات طلاب أو مزامنة سحابية حتى الآن.
- بعض المتصفحات لا تدعم تثبيت PWA أو كل صيغ الأيقونات بالطريقة نفسها.
- لا توجد حالياً خدمة ذكاء اصطناعي توليدي؛ الأولوية لبناء تجربة تعليمية مفيدة تعمل دون اشتراك أو اتصال دائم.

## التقنية

HTML + CSS + JavaScript دون إطار عمل أو اعتماديات خارجية، مع Web App Manifest وService Worker.
